<h2>프로젝트 주요 기능</h2>
<p><strong>Kurlypool Recommender</strong>는 마켓컬리 리뷰 데이터를 기반으로 다음과 같은 기능을 제공합니다:</p>

<ul>
  <li><strong>📊 자동 평점 예측 시스템</strong><br>
    리뷰 텍스트를 기반으로 감정을 분석하여 1~5점 평점을 자동으로 산출합니다.
  </li>
  <li><strong>🏷️ 자동 해시태그 생성 시스템</strong><br>
    리뷰 속 키워드를 분석하여 감정 기반 해시태그를 자동으로 생성합니다.
  </li>
  <li><strong>🧠 AI 챗봇 기반 추천 시스템</strong><br>
    사용자 조건(연령, 지역, 가구원 수 등)에 따라 맞춤형 간편식을 추천합니다.
  </li>
  <li><strong>🤖 AI 챗봇 UI (Kurlypool Chatbot)</strong><br>
    선택형 + 자유 입력형 인터페이스를 통해 추천/트렌드/재구매 등 다양한 시나리오를 지원합니다.
  </li>
</ul>
